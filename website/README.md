# PulseEdge-OS (Sahayak) — Official Website

Official website for **PulseEdge-OS (Sahayak Physical & Neural Diagnostic Edition)** submission for the **iQOO Hackathon (HealthTech Track)**.

## Features
- **100% Offline Edge-AI Showcase**: Details the Snapdragon NPU runtime and OriginOS cross-device architecture.
- **Biophysical Diagnostics**: Acoustic Stethoscope (Audio FFT 200–1000 Hz), Sclera/Conjunctiva Scanner, and Camera PPG (Heart Rate & SpO2).
- **Zero-Touch Neuro-Accessibility**: MediaPipe 60 FPS iris gaze tracking, micro-gestures, breath/puff click triggers, and Parkinson's tremor filtering.
- **Rural Pharma & Telemetry**: Pradhan Mantri Jan Aushadhi generic mapping (up to 85% cost savings), CDSCO drug contraindication shield, and OriginOS Multi-Window Doctor HUD with Super Clipboard sync.
- **Interactive On-Page Simulator**: Test all 6 core sub-systems directly in the browser.
- **Direct APK Download**: Instant access to `Sahayak-Release-v1.0.apk`.

## Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Development Server
```bash
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.

### 3. Build for Production
```bash
npm run build
```
The production bundle will be generated in the `dist/` directory.

### 4. Preview Production Build
```bash
npm run preview
```
